  DebugLogCollector. Stable game 0.4.6f13 uses ScheduleOne.Reporting.
  DebugLogCollector, leaving its throwing callback unguarded.
- Add a shared, optional Harmony patch for the current game's HandleLog callback.
  Dedicated server and dedicated client sessions bypass the feedback buffer.
  Normal single-player/co-op sessions keep it; other logging listeners remain.
- Regression checks apply the real Harmony patch to a throwing managed callback
  under both runtime names and both server/client build defines.
- Exclude nested test build artifacts from the mod's assembly candidates so
  the test's Harmony DLL cannot supersede the game's Harmony reference.
